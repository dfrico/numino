# Contributing to Numino

Thanks for taking the time. Bug reports, small fixes and format or feature requests are all welcome.

## Before you start

- Check the [open issues](../../issues) so we don't duplicate work.
- For anything bigger than a small fix, open an issue first and describe what you'd like to change and why. It saves us both time if the direction is agreed before the code exists.

## Setting up

```
npm install && npm run dev
```

## Checking your change

npm test (needs a server running), npm run typecheck, npm run lint

## Pull requests

- One change per pull request, with a short description of what it does and why.
- Keep the user-facing docs (the README) in sync with what you change.
- Follow the style of the surrounding code. There's no formatter to fight; just match what's there.
- By contributing you agree that your contribution is licensed under the project's [license](LICENSE).

## Reporting bugs

Use the bug report template. The most useful things to include are what you did, what you expected, what happened instead, and your browser or runtime version.
